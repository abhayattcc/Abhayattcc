## Features
The Kid-Friendly Website Explorer is packed with features to make browsing fun and educational:
- **Vibrant, Kid-Friendly Design**: Bright gradient backgrounds, playful 'Comic Neue' font, and rounded buttons create an inviting experience for children.
- **Interactive Animations**: Bounce animations on buttons and pulse effects on the home screen keep kids engaged.
- **Responsive Layout**: Works seamlessly on desktops, tablets, and mobile devices, ensuring accessibility for all users.
- **Dynamic Navigation**: Large, colorful buttons hide upon selection to display full-screen website content, with a "Back to Home" button for easy navigation.
- **Iframe Integration**: Safely embeds four educational websites within the app, with one opening in a new tab for optimal performance.
- **SEO-Optimized Structure**: Descriptive headings, keywords, and alt text enhance discoverability on search engines like Google.
- **Accessible Design**: Clear, scannable content with alt text for images ensures inclusivity for all users.
- **Fast Loading**: Optimized code and minimal dependencies ensure quick page loads, improving user experience and SEO.

## How It Works
The explorer starts with a welcoming home screen displaying animated buttons for five websites. Clicking a button (except "Web to APK") hides the navigation and loads the selected website in a full-screen iframe with a smooth transition. A "Back to Home" button appears to return to the main menu. The "Web to APK" button opens its website in a new tab for a seamless experience. The design prioritizes simplicity, making it easy for kids to navigate while maintaining a fun, engaging aesthetic.
